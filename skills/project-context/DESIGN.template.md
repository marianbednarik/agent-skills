# Design

_Durable visual and interaction direction. Keep this lean: no exhaustive token dumps, component inventories, or fake precision._

## Overview

The design intent, mood, density, and interaction feel in plain language.

## Colors

Palette direction, known colors if settled, and color habits to avoid.

## Typography

Type personality, hierarchy, readability expectations, and exact fonts only when chosen.

## Layout

Responsive posture, mobile/desktop expectations, navigation shape, spacing density, and page structure preferences.

## Elevation & Depth

How the interface uses borders, shadows, layering, surfaces, or flatness.

## Shapes

Radius, geometry, icon style, sharpness or softness, and recurring visual forms.

## Components

Project-standard UI patterns and component expectations that should guide future work.

## Do's and Don'ts

Short, forceful design guardrails.
